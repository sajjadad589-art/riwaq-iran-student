# وياك — دليل المسافر العراقي في ايران

تطبيق PWA عربي RTL بواجهة شاشات مستقلة، خريطة Leaflet/OSM، عبارات فارسية، دليل طلاب وخدمات واتساب ومصاريف محلية. التطبيق مجاني وغير تجاري بحسب تعليمات صاحبه؛ لا رسوم ولا إعلانات.

## التشغيل والتحقق
Node.js 22 أو أحدث. npm ci ثم npm test وnpm run build. معاينة الواجهة: npx vite preview --port 4173 ثم npm run test:browser. اختبارات المتصفح تحاكي المصادر وتسرّع الوقت للتحقق من فحص 20 دقيقة، وتختبر فشل التحديث والتحويل والمصاريف والتنقل والبحث والعمل دون اتصال. لا تثبت اختبارات البحث المحاكاة اكتمال الأماكن عند المزود.

## أسعار السوق المجانية
- إيران: Nerkhsanj، https://nerkh.jahankhahan.shop/data/live.json — الدولار بالتومان، تاريخ شمسي ووقت طهران. بيانات استرشادية للسوق الحر، وليست عرض شراء وبيع قابل التنفيذ. المصدر: https://github.com/hamidjh80-arch/nerkhsanj-api
- العراق: IQWealth (iraqsm.com)، https://iraqsm.com/data/fx.json — نستخدم parallel.buy وparallel.sell حصراً. المحول يستخدم متوسطهما. المصدر والرابط ظاهرين. الاستخدام غير التجاري وفق وصف صاحب التطبيق وشروط المصدر المنشورة.

Pages Function في functions/api/market.js يجلب السوقين باستقلال ويفحص البيانات، ويخزّن الاستجابة الناجحة لكل مزود على الحافة لمدة 20 دقيقة لتقليل الطلبات. لا يحتاج مفاتيح أو اشتراك. لا يستخدم official أو APIs العملات الرسمية. تعطل سوق لا يخفي السوق الآخر. تُرفض القيم غير الصالحة والتواريخ المستقبلية وأكثر من سبعة أيام؛ القراءة الأقدم من ست ساعات موسومة قديمة. عند إغلاق السوق الإيراني وعدم توفر وقت، يُعرض تاريخ الإغلاق ولا يُختلق توقيت.

التطبيق يفحص كل 20 دقيقة أثناء فتحه، ويعيد الفحص عند عودة الاتصال أو الرجوع بعد تأخر الموعد. العداد يحسب من نهاية آخر محاولة. زر التحديث يطلب آخر قراءة متاحة من الخادم وقد يستفيد من الكاش حتى 20 دقيقة؛ لا يعني نشر سعر جديد عند المزود. ليس تحديثاً خلفياً عند إغلاق التطبيق. آخر بيانات سوق تحفظ على الجهاز مع علامة محفوظة عند الفشل، ولا تُستبدل بالسعر الرسمي. يجوز إدخال سعر الصرّاف يدوياً. لا يُخزن موقع GPS.
