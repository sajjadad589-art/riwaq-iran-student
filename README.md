# وياك — دليل المسافر العراقي في ايران

تطبيق PWA عربي RTL بواجهة شاشات مستقلة، خريطة Leaflet/OSM، عبارات فارسية، دليل طلاب وخدمات واتساب ومصاريف محلية. التطبيق مجاني وغير تجاري بحسب تعليمات صاحبه؛ لا رسوم ولا إعلانات.

## التشغيل والتحقق
Node.js 22 أو أحدث. npm ci ثم npm test وnpm run build. معاينة الواجهة: npx vite preview --port 4173 ثم npm run test:browser. اختبارات المتصفح تحاكي المصادر وتسرّع الوقت للتحقق من فحص 20 دقيقة، وتختبر فشل التحديث والتحويل والمصاريف والتنقل والبحث والعمل دون اتصال. لا تثبت اختبارات البحث المحاكاة اكتمال الأماكن عند المزود.

## أسعار السوق المجانية
- إيران: Nerkhsanj، https://nerkh.jahankhahan.shop/data/live.json — الدولار بالتومان، تاريخ شمسي ووقت طهران. بيانات استرشادية للسوق الحر، وليست عرض شراء وبيع قابل التنفيذ. المصدر: https://github.com/hamidjh80-arch/nerkhsanj-api
- العراق: IQWealth (iraqsm.com)، https://iraqsm.com/data/fx.json — نستخدم parallel.buy وparallel.sell حصراً. المحول يستخدم متوسطهما. المصدر والرابط ظاهرين. الاستخدام غير التجاري وفق وصف صاحب التطبيق وشروط المصدر المنشورة.

Pages Function في functions/api/market.js يجلب السوقين باستقلال ويفحص البيانات، ويخزّن الاستجابة الناجحة لكل مزود على الحافة لمدة 20 دقيقة لتقليل الطلبات. لا يحتاج مفاتيح أو اشتراك. لا يستخدم official أو APIs العملات الرسمية. تعطل سوق لا يخفي السوق الآخر. تُرفض القيم غير الصالحة والتواريخ المستقبلية وأكثر من سبعة أيام؛ القراءة الأقدم من ست ساعات موسومة قديمة. عند إغلاق السوق الإيراني وعدم توفر وقت، يُعرض تاريخ الإغلاق ولا يُختلق توقيت.

التطبيق يفحص كل 20 دقيقة أثناء فتحه، ويعيد الفحص عند عودة الاتصال أو الرجوع بعد تأخر الموعد. العداد يحسب من نهاية آخر محاولة. زر التحديث يطلب آخر قراءة متاحة من الخادم وقد يستفيد من الكاش حتى 20 دقيقة؛ لا يعني نشر سعر جديد عند المزود. ليس تحديثاً خلفياً عند إغلاق التطبيق. آخر بيانات سوق تحفظ على الجهاز مع علامة محفوظة عند الفشل، ولا تُستبدل بالسعر الرسمي. يجوز إدخال سعر الصرّاف يدوياً. لا يُخزن موقع GPS.

## تحسينات الاستخدام
أرقام مالية بفواصل أوضح، أوقات مستقلة للسوقين، اتجاهات تحويل سريعة ونسخ النتيجة والتحقق من المبلغ، و24 عبارة مع فلاتر وحالة بحث فارغة. الخريطة تتضمن قائمة ثماني مدن وحفظ حتى 50 مكاناً محلياً وفتح الاتجاهات في Google Maps. GPS غير محفوظ؛ أما إحداثيات الأماكن التي يختار المستخدم حفظها فتحفظ على جهازه ويمكن حذفها. تحميل بلاطات الخريطة يبدأ عند فتح قسمها. قائمة تجهيز من ست مهام وميزانية رحلة محفوظتان محلياً، مع مؤشر تجاوز الميزانية. زر الرجوع يعيد القسم السابق. البيانات المحلية لا تتزامن بين الأجهزة. الاختبارات الإضافية في tests/enhancements-browser.mjs تشمل حفظ البيانات بعد إعادة الفتح وشاشات 320 و390 و480 بكسل.

توسعة دليل الفارسية: 194 كلمة وعبارة إجمالاً، منها 30 للشارع و30 للمطعم و30 للكافيه و30 للخضار و30 للفواكه و20 إضافية للشراء والدفع. لكل بطاقة معنى عربي ونص فارسي ونطق عربي تقريبي. البحث يتجاهل التشكيل والاختلاف بين ك/ک وي/ی والمسافات والفاصل الفارسي. المحتوى مضمن محلياً ضمن التطبيق ومتاح دون اتصال بعد التخزين الناجح. لا تتضمن البطاقات تسجيلاً صوتياً. البيانات في phrasebook.js.


## الحسابات ولوحة الإدارة
الدخول الإلزامي من «حسابي» برقم هاتف وكلمة مرور لا تقل عن 6 أحرف أو أرقام. الأرقام العراقية توحّد إلى الصيغة الدولية، وقيد UNIQUE يمنع تكرار الرقم حتى مع الطلبات المتزامنة. لا SMS ولا مكالمة ولا ادّعاء تحقق ملكية الرقم: phone_verified يبقى 0. كلمات المرور scrypt N=32768,r=8,p=3 مع ملح عشوائي. الجلسات ملفات تعريف ارتباط HttpOnly/Secure/SameSite وتُخزن بصمة الرمز فقط، وتنتهي بعد ثلاثة أيام. يوجد تحديد لمحاولات الدخول وفحص Origin للطلبات المغيّرة.

قاعدة D1 wayak-management مربوطة باسم DB. migrations/0001_admin.sql ينشئ الجداول بصورة إضافية دون حذفها. حساب المدير يُنشأ بدعوة عشوائية ذات استخدام واحد تنتهي بعد 24 ساعة؛ لا كلمة مرور افتراضية ولا ترقية تلقائية لحساب أول مسجل. رقم المدير محجوز بدعوة داخل قاعدة البيانات، وليس ثابتاً في الواجهة أو المستودع. الدعوة خاصة بصاحب التطبيق.

لوحة #admin تتطلب دور admin من الخادم. تتيح تحرير نصوص وروابط الأقسام، إتاحة الأقسام أو إيقافها، إضافة بطاقات، إدارة العبارات، ورفع صور PNG/JPEG/WebP حتى 500KB للإعلانات مع القسم والموعد والرابط والتفعيل. تُنشر البيانات في D1 دون إعادة بناء التطبيق، ويقرأها الزائر عند التنقل أو الرجوع أو خلال دقيقة. العرض دون اتصال يستعمل آخر محتوى محفوظ. التغييرات البرمجية في وظائف التطبيق نفسها ما زالت تحتاج نشراً. تُحفظ نسخ سابقة للمحتوى مع حماية تعارض التعديلات؛ يمكن تحميل نسخة إلى المحرر ثم نشرها.

لوحة المستخدمين تعرض آخر 200 حساب والعدد الكلي وتسمح بإنهاء الجلسات. لا توجد استعادة كلمة مرور عبر الهاتف ولا تزامن تلقائي لمصاريف وأماكن الجهاز. تسجيل الدخول لا يرفع البيانات المحلية إلى الخادم. لا تُخزّن بيانات جلسات الإدارة في Service Worker.

اختبارات الإدارة: شغّل wrangler pages dev dist --port 8788 مع DB محلي. tests/management-browser.mjs يستعمل دعوة اختبار محلية ثابتة فقط؛ لا تستعملها بالإنتاج. اختبارات الإنتاج تُنشئ حساب فحص مؤقتاً وتزيله بعد التحقق.


## الدخول الإلزامي وإحصائيات الحضور
كل فتح جديد للتطبيق يحتاج التحقق من جلسة الخادم، والزائر يُحوّل إلى #account حتى لو فتح رابط قسم مباشر. حُذف الدخول كضيف، وAPI المحتوى والأسعار والصور والإدارة يتطلب جلسة صالحة. لا توجد علامة في localStorage تمنح الدخول. إذا أُعيد فتح التطبيق دون إنترنت فلا يُفتح المحتوى حتى التحقق من الجلسة؛ خلال جلسة مفتوحة يمكن استعمال البيانات المحلية دون اتصال. قيد الدخول الإلزامي يسبق ميزة الفتح دون اتصال.

تطبيق migrations/0002_presence.sql يضيف تاريخ آخر دخول وآخر نشاط وجدول حضور لكل جلسة وتبويب. نبضة حضور كل 30 ثانية للتبويب الظاهر فقط، وحذف حضوره عند إخفائه أو إغلاقه قدر الإمكان. الاتصال تقديري: نبضة خلال آخر دقيقتين مع جلسة غير منتهية، مع COUNT DISTINCT للمستخدم كي لا تتكرر التبويبات والأجهزة. الخروج وإلغاء الجلسات يزيل الحضور المرتبط فوراً. الحضور لا يسجل GPS أو الصفحات المفتوحة.

لوحة الإدارة تعرض إجمالي الحسابات (بما فيها المدير)، ومن دخلوا مرة على الأقل، ومن أنشأوا جلسة دخول اليوم بتوقيت بغداد، والمتصلين حالياً. إنشاء الحساب يسجّل دخولاً تلقائياً. السجلات القديمة وُسمت بدخول عند الإنشاء لأن النسخة السابقة كانت تنشئ جلسة تلقائية؛ تواريخ الدخول التالية لا يمكن استعادتها بأثر رجعي. الإحصائيات تُحدّث كل 30 ثانية أثناء عرض لوحة الإدارة أو يدوياً. اختبارات tests/gate-presence-browser.mjs تعمل مع D1 محلي وتتحقق من الحماية والعدّ الفريد والخروج وإعادة الفتح دون اتصال.
