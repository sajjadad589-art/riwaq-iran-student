# وياك — الطالب العراقي في إيران

تطبيق عربي RTL قابل للتثبيت، خريطة Leaflet/OSM، بحث إيران Nominatim، بحث قريب Overpass، تحويل USD/IQD/IRR/تومان، وعبارات فارسية وخدمات واتساب.

## تشغيل وفحص
Node.js 22 أو أحدث. نفّذ `npm ci` ثم `npm test` و`npm run build`. للمعاينة `npm run dev`.

## النشر على Cloudflare Pages مع GitHub
ارفع المشروع إلى مستودع GitHub. من Cloudflare اختر Workers & Pages → Create → Pages → Connect to Git. اختر المستودع وmain، أمر البناء `npm run build`، مجلد الناتج `dist`، ومتغير NODE_VERSION بقيمة 22. امنح Cloudflare الوصول لهذا المستودع فقط. يصبح كل push بناءً ونشراً تلقائياً. لا يلزم Vercel ولا مفاتيح API.

تحقق من الرابط الناتج عبر HTTPS ومن manifest وsw.js وتثبيت التطبيق. سماح الموقع بيد المستخدم والمتصفح. الخرائط وأسعار جديدة تحتاج إنترنت؛ الواجهة والعبارات وآخر سعر محفوظ تعمل دون اتصال بعد زيارة ناجحة.

## مصادر وحدود
ExchangeRate-API المفتوح يحدّث بياناته يومياً، والفحص في التطبيق كل 20 دقيقة أثناء فتحه مع زر يدوي. ليس تغذية لسعر السوق الإيراني. المصدر وتوقيته ظاهران؛ سعر السوق قابل للإدخال يدوياً وغير محفوظ. لا تُختلق أسعار عند الفشل. لا تحديث خلفي مجدول عند إغلاق التطبيق.
Nominatim بحث يدوي فقط مع فاصل بين الطلبات، countrycodes=ir؛ Overpass بحث حول مركز الخريطة حتى 5 كم. الخدمات العامة محدودة وقد تفشل أو تخلو من أماكن. عند نمو الاستخدام يلزم مزود مناسب أو استضافة خدمات البحث. لا يجري تخزين موقع المستخدم. الإحداثيات تُرسل لمزود الخرائط/البحث عند استخدامه.
خدمات الطلاب روابط استفسار وليست تأكيد توفر خدمة أو قبول جامعي.

لم يُنشر هذا المشروع إلا بعد توثيق رابط Cloudflare واختباره في المحادثة.
